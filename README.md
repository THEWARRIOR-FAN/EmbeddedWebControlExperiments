# EmbeddedWebControlExperiments

基于网页技术的控制系统仿真实验集合：用可交互的界面直观理解不同控制模型的工作原理与参数调节方法。

**纯前端实现** —— HTML5 + CSS3 + JavaScript + Canvas，无依赖、无构建、无后端，下载即可运行。

## 功能特性

- 实时水位仿真与可视化，目标水位可调
- Kp / Ki / Kd 滑块 + 微调按钮，参数改动即时生效
- 核心区只放关键量：当前液位、目标、误差、实际阀位四个大字指标
- PID 公式卡：P/I/D 每项单独一行，代入当前误差、参数、水位速度的真实数值，颜色区分，末行显示限幅与延迟路径
- 进出水平衡一行提示（净进/净出/平衡），帮助理解稳态
- 次要数据（仿真时间、存水、理论静差、累计溢流）默认折叠，物理模型说明收入左侧折叠区
- 实验预设附带预期现象说明，帮助带着问题观察曲线
- Canvas 实时响应曲线，可暂停并拖动回看任意历史时段
- 基于真实单位的体积守恒和底部小孔出流模型
- 推荐 PI 参数与 P / PI / PID 三组实验预设（不是在线自动整定）
- 1× / 10× / 60× 仿真倍速，固定物理步长，不依赖显示帧率

## 当前实验：PID 调参（`pid-tuner.html`）

**实验目的**：理解 PID 控制器的工作原理，掌握 Kp、Ki、Kd 对系统性能的影响。

**推荐调参顺序**

1. 先了解被控对象的特性，再从 `Ki=0`、`Kd=0` 开始逐步增加 `Kp`，观察速度、静差和振荡。
2. 再逐步增加 `Ki` 消除静差，观察是否引入超调或振荡。
3. 最后才试 `Kd`，并结合曲线验证它对当前对象是否有帮助。每次只改一个参数。
4. 滑块范围只是本教学仿真的操作边界，不是现实设备预先已知的整定答案。

**预设参数与预期现象**（目标水位 0.6 m）

| 预设 | Kp | Ki | Kd | 现象 |
| --- | --- | --- | --- | --- |
| 默认 / P 控制 | 200 | 0 | 0 | 稳定在约 0.459 m，静差约 0.141 m |
| PI 控制 | 200 | 0.2 | 0 | 静差消失、几乎无超调，最终到达 0.6 m |
| PID 控制 | 200 | 0.2 | 20000 | 与 PI 仅差 D：实测多约 21 mm 超调 |

Kp、Ki、Kd 的单位分别为 `%/m`、`%/(m·s)`、`%·s/m`。实际注水需要几分钟，默认用 10× 倍速观察，界面时间始终是仿真秒。

**本模型中的参数范围**（仅为仿真操作边界，不是 PID 设计结果）

| 参数 | 范围 | 依据 |
| --- | --- | --- |
| Kp | 0–1000 | 操作边界；用于观察比例作用，不代表建议值。纯 P 临界增益约 500000 是本简化模型的探索结果，不应作为现场整定目标 |
| Ki | 0–5 | 操作边界；用于观察积分消差及超调变化 |
| Kd | 0–20000 | 操作边界；放大本模型中较小的微分作用以便观察 |

本模型现象供测试后对照：纯 P 有静差；Ki 增大可消除静差但可能增加超调；本模型加大 Kd 实测反而增大超调。Kp 接近 0 且 Ki 较大时会持续振荡。

**仿真模型**：1 m × 1 m × 1 m 敞口水池，顶部进水最大 2 L/s，底部直径 20 mm 的小孔自由排水，流量系数 Cd=0.6。

```text
Qin = 0.002 × 实际阀门开度 / 100                  (m³/s)
Qout = 0.6 × π × 0.020² / 4 × √(2 × 9.81 × h)  (m³/s)
h_next = h + (Qin - Qout) / 1.0 × dt             (m)
```

0.6 m 时存水 600 L，出水约 0.647 L/s，平衡阀位约 32.4%。阀门指令纯延迟 0.3 s，一阶响应时间常数 1 s；测量微分低通时间常数 0.5 s。采用 0.05 s 固定步长、条件积分抗饱和，超出池顶的水计入累计溢流。理论静差是平衡解预测，不代表任意参数都能稳定收敛。目标滑块最高 0.8 m，距池顶有 0.2 m 余量，实测滑块拉满（Kp=1000、Ki=5、Kd=20000）也不会溢流，因此该读数默认折叠、仅作异常指示。

该模型不包含长管阻力、泵曲线、非线性阀门特性及水面晃荡。物理参数集中在 `pid-tuner.html` 的 `tankArea`、`tankHeight`、`maxInflow`、`outletDiameter` 等常量处；修改时需同步调整页面说明、预设和文档。水池容量仅由截面积乘池高确定，不能单独用容量推出目标水位。

**验证**（需 Node.js，无第三方依赖）：

```bash
node --test tests/water-model.test.cjs
```

覆盖流量、进出水平衡、P 静差、PI/PID 收敛、目标下降、空池/满池、帧率独立性、暂停重置与历史时间戳，以及 PID 分项拆解、限幅抗饱和和预设说明。
